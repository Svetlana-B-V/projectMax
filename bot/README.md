# Telegram-бот «Общак»

Бот ходит в бэкенд **только по HTTP API** (`http://localhost:3000`). Свою SQLite использует для сессий, привязки чатов и дедупликации апдейтов.

## Запуск

Нужны Python 3.12+, [uv](https://docs.astral.sh/uv/) и запущенный бэкенд ветки `back`.

```powershell
cd bot
copy .env.example .env   # вписать BOT_TOKEN
uv sync
uv run python -m obshak_bot
```

Тесты: `uv run pytest -q`. Линтер: `uv run ruff check .`

## Что умеет

| Кнопка | Действие |
|---|---|
| 💸 Расход | Сумма → категория → описание → плательщик → участники → доли |
| 📷 Чек | Фото: фискальный QR, иначе заглушка `POST /api/expenses/receipt` |
| 💰 Долги | Кто кому сколько, возврат целиком или частью |
| 🐷 Копилки | Список, создание, взнос. Остаток от деления «поровну» уходит сюда |
| 🔔 Напоминания | Стиль и вкл/выкл; не чаще раза в сутки, если есть долги |
| 🏆 Достижения | Каталог + прогресс |
| 👥 Группы | Создать / вступить / текущая / ссылка-приглашение |

Если расход добавляет не плательщик — бот спрашивает того в личке. «Нет» отменяет расход.

В групповом чате: добавили бота → создаётся группа «Общака»; написавшие автоматически вступают.

## Достижения (бэкенд)

`GET /api/achievements`, `POST /api/achievements/check`

- Первый шаг — первый расход
- Бухгалтер — 3 расхода
- Честный должник — первый возврат долга
- Белочка — взнос в копилку
- Хозяин — создание группы
